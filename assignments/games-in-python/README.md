# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique a manipulação de strings, listas, loops, condicionais e entrada de dados criando uma versão jogável do clássico Jogo da Forca.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo em que o jogador tenta adivinhar uma palavra oculta, uma letra por vez, antes de esgotar o número de tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir o progresso da palavra com letras adivinhadas e espaços em branco, por exemplo, `_ _ _`.
- Solicitar palpites de letras e revelar todas as ocorrências da letra na palavra.
- Acompanhar e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota; em caso de derrota, revelar a palavra.
